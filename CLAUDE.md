# Правила проекта

- Никогда не выдумывай данные бизнеса. Нет данных — поле пустое, соответствующий блок на странице скрыт.
- Отзывы — только пересказом реальных исходных отзывов, без имён авторов. Нет исходных отзывов — блок скрыт.
- На каждой странице показывай плашку: «Демо-концепт, не официальный сайт, удалим по первой просьбе».
- Запрети индексацию всех страниц: `<meta name="robots" content="noindex, nofollow">` в каждом HTML-файле.
- Стек: статические HTML/CSS/JS, один скрипт сборки, без фреймворков.
- Мобильная вёрстка в приоритете.
- В начале сессии читай PLAN.md; после завершения шага обновляй текущее состояние и следующие действия.
