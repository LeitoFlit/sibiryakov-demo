# Память проекта

## Текущий шаг
Концепт «Сибиряковъ» (зимняя/новогодняя версия в стиле Posthotel) перенесён в репозиторий и приведён к правилам проекта. В репозитории два демо-сайта на GitHub Pages:
- Сибиряковъ (зимний концепт): https://leitoflit.github.io/sibiryakov-demo/
- Новый год в «Сибирякове»: https://leitoflit.github.io/sibiryakov-demo/novyi-god/

## Что готово
- Создан приватный репозиторий LeitoFlit/sibiryakov-demo.
- Перенесены исходники из архива sibiryakov1.zip: `src/` (страницы, компоненты, стили, скрипты), `public/assets/` (видео, фото, шрифты, логотип), `scripts/build.mjs` (единственный скрипт сборки, только встроенные модули Node), `scripts/serve.mjs`.
- `dist/` не хранится в git, собирается командой `npm run build`.
- Добавлен `src/components/shared/demo-notice.html` — плашка «Демо-концепт, не официальный сайт, удалим по первой просьбе» над шапкой на обеих страницах.
- Добавлен `<meta name="robots" content="noindex, nofollow">` в `index.html` и `hotel.html`.
- Версия стилей и скрипта в ссылках поднята до `?v=5`.
- Проверено на ширине 375 и 1440 px: плашка не перекрывает шапку, горизонтальной прокрутки нет, ошибок JS нет.
- Репозиторий сделан публичным, включён GitHub Pages (Source: GitHub Actions). `.github/workflows/pages.yml` собирает `dist/` и публикует при каждом push в `main`; первая публикация прошла успешно 27.10.2026.
- Добавлены анимации (`src/styles/04-motion.css`, `src/scripts/11-motion.js`): плавный переход между страницами (View Transitions), индикатор прокрутки, проявление первого экрана, появление блоков при прокрутке, раскрытие фото рамкой, волна карточек в лентах, проявление фото и текста при переключении (сюжеты, галерея, спа), шапка прячется при прокрутке вниз, панель бронирования выезжает снизу, окна и меню открываются и закрываются плавно, плавное раскрытие FAQ, отклик кнопок и стрелок. При «уменьшении движения» в системе всё показывается сразу. Проверено на 375 и 1440 px: ошибок нет, горизонтальной прокрутки нет, все видимые блоки проявляются.
- Добавлена страница «Новый год» (`src/pages/novyi-god/index.html`, один файл со стилями и скриптом) из артефакта claude.ai/artifact/8KTVUkziEhJ7TXcdZoECbq. Приведена к правилам: убраны выдуманные программа ночи, тарифы «Ночь / Каникулы / Коттедж» с ценами-заглушками, даты 31.12–02.01 и перечень развлечений; заглушки контактов заменены проверенными (почта не найдена — убрана); форма заявки, которая никуда не отправляла данные, заменена ссылками на звонок, Telegram и бронирование на sibiryakov.club; фото-заглушки заменены фото из `assets/`, видео берётся из общего `assets/hotel.mp4`. Добавлены плашка демо-концепта, noindex, появление блоков при прокрутке. `scripts/build.mjs` теперь создаёт подпапки для страниц.

## Что дальше
1. Если отель даст настоящую новогоднюю программу и тарифы — вернуть на страницу «Новый год» блоки программы и тарифов.
2. Получить отзыв об анимациях (скорость, количество) и подстроить.
3. Собрать отзывы о концепте и внести правки в `src/`; после push сайт обновится сам за 1–2 минуты.
4. Периодически сверять цены и даты с официальным сайтом.

## Как продолжить
Прочитать CLAUDE.md и этот файл. Править исходники в `src/`, затем `npm run build`. После работы обновить текущий шаг, готовое и дальнейшие действия.
