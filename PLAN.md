# Память проекта

## Текущий шаг
Подготовка к работе. Правила записаны; бизнес, исходные данные и страницы пока не определены. Разработка сайта не начата.

## Что готово
- Создан CLAUDE.md с краткими правилами проекта.
- Создан PLAN.md для продолжения работы после очистки контекста или смены сессии.
- Создан приватный репозиторий GitHub LeitoFlit/sibiryakov-demo, в него добавлены CLAUDE.md и PLAN.md.

## Что дальше
1. Получить задачу: для какого бизнеса создаётся демо, какие страницы нужны и где лежат исходные материалы.
2. Зафиксировать подтверждённые данные и их источники; отсутствующие данные не заполнять.
3. Создать мобильную статическую вёрстку и один скрипт сборки без фреймворков.
4. Проверить плашку и запрет индексации на каждой странице, скрытие блоков без данных и отображение на мобильных экранах.
5. Решить, как показывать сайт для тестирования: GitHub Pages на приватном репозитории требует платного тарифа GitHub.

## Как продолжить
Прочитать CLAUDE.md и этот файл, затем выполнить следующий незавершённый шаг. После работы обновить текущий шаг, готовое и дальнейшие действия; записать препятствия и важные решения, если они появились.
