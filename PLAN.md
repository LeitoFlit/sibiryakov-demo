# Память проекта

## Текущий шаг
Концепт «Сибиряковъ» (зимняя/новогодняя версия в стиле Posthotel) перенесён в репозиторий и приведён к правилам проекта. Следующее — решить, где показывать сайт для тестирования.

## Что готово
- Создан приватный репозиторий LeitoFlit/sibiryakov-demo.
- Перенесены исходники из архива sibiryakov1.zip: `src/` (страницы, компоненты, стили, скрипты), `public/assets/` (видео, фото, шрифты, логотип), `scripts/build.mjs` (единственный скрипт сборки, только встроенные модули Node), `scripts/serve.mjs`.
- `dist/` не хранится в git, собирается командой `npm run build`.
- Добавлен `src/components/shared/demo-notice.html` — плашка «Демо-концепт, не официальный сайт, удалим по первой просьбе» над шапкой на обеих страницах.
- Добавлен `<meta name="robots" content="noindex, nofollow">` в `index.html` и `hotel.html`.
- Версия стилей и скрипта в ссылках поднята до `?v=5`.
- Проверено на ширине 375 и 1440 px: плашка не перекрывает шапку, горизонтальной прокрутки нет, ошибок JS нет.
- Данные бизнеса сверены с sibiryakov.club 27.10.2026: открытие 15.12.2026, телефон +7 (812) 237-70-10, адрес аллея Линтульская 38/14, Telegram t.me/veresk_park, цены от 30 000 / 35 000 / 42 000 / 50 000 ₽ (Делюкс / Люкс / Сьют / Сьют с камином). Отзывов на сайте нет.
