# Сибиряковъ — сайт по компонентам

Полные исходники версии в стиле Posthotel, опубликованной 22 октября 2026 года.

**Демо-концепт, не официальный сайт.** На каждой странице есть плашка об этом и запрет индексации (`noindex, nofollow`). Правила проекта — в `CLAUDE.md`, текущее состояние — в `PLAN.md`. Сохранены новогодняя тема, оригинальное видео отеля, фотографии, две страницы и интерактивные элементы.

## Быстро открыть

Выполните `npm run build`, затем откройте `dist/index.html` в браузере. Это собранный сайт: HTML, CSS, JavaScript и все медиа находятся внутри архива. Для обычного просмотра не нужны Node.js, установка пакетов или подключение к интернету. Внешние ссылки на бронирование, карту и контакты требуют интернета.

Для локальной разработки с веб-сервером нужен Node.js 20 или новее:

```sh
npm run build
npm start
```

Откройте `http://localhost:8080`. Команды выполняются из папки с `package.json`. `npm install` не нужен: сборка и сервер используют только встроенные модули Node.js. После правок повторите `npm run build` и обновите страницу.

|---|---|

| `src/pages/index.html` | Порядок компонентов главной страницы |
| `src/pages/hotel.html` | Порядок компонентов страницы номеров |
| `src/pages/novyi-god/index.html` | Отдельная страница «Новый год» (стили и скрипт внутри файла), открывается по адресу `/novyi-god/` |
| `src/components/shared/` | Общие шапка, меню, подвал, панель и окна бронирования |
| `src/components/home/` | Секции главной страницы |
| `src/components/hotel/` | Секции каталога и четыре отдельных номера |
| `src/scripts/` | JavaScript по функциям интерфейса |
| `src/styles/` | Базовые стили, компоновка каталога и финальная тема Posthotel |
| `public/assets/` | Видео MP4, фотографии, логотип SVG, иконка и локальные шрифты |
| `scripts/build.mjs` | Сборка компонентов в обычные HTML-страницы |
| `scripts/serve.mjs` | Локальный сервер для просмотра `dist/` |

| `COMPONENTS.md` | Описание компонентов и их связей |

## Как менять сайт

1. Тексты и разметку редактируйте в `src/components/`.
2. Порядок секций меняйте в `src/pages/`. Запись `{{> src/components/shared/header.html }}` вставляет компонент при сборке. Вложенные вставки поддерживаются.
3. Итоговые цвета, шрифты, отступы и адаптивность меняйте в `src/styles/03-posthotel-theme.css`. Он подключается последним и переопределяет базовые стили.
4. Фотографии и видео заменяйте в `public/assets/`. При смене имени файла поправьте пути в HTML и JavaScript.
5. Поведение элементов меняйте в соответствующем файле `src/scripts/`.
6. Выполните `npm run build`. На хостинг загружайте **содержимое `dist/`**, сохраняя структуру папок.

Не редактируйте только `dist/`, если собираетесь собирать проект заново: повторная сборка перезаписывает сгенерированные файлы. Версия в этом архиве не изменяет опубликованный сайт автоматически.

## Перенос компонентов в другой проект

Это обычные HTML-фрагменты, не React/Vue-компоненты. Их можно вставить в шаблоны CMS или другую HTML-страницу. Подключайте `style.css`, `ritz.css`, `posthotel.css` именно в таком порядке, затем `app.js` перед закрывающим `</body>`. Имена CSS-файлов сохранены для совместимости с текущим сайтом.

JavaScript собирается в один классический скрипт с общей областью видимости. Порядок в `build.config.json` важен. Не подключайте исходные фрагменты как независимые `type="module"` без адаптации. Скрипты ожидают общие компоненты меню, бронирования и диалога; при переносе одного блока подключайте только нужную ему логику и зависимости из `COMPONENTS.md`.

## Что работает и что требует подключения

Работают меню, ручное переключение четырёх сюжетов, видео с паузой, галерея номеров, описания номеров, спа-вкладки, FAQ, выбор дат и сводка пребывания. Видеофон учитывает системную настройку уменьшения анимации.

Сайт не связан с PMS/TravelLine и не проверяет наличие номеров. Финальное действие переводит на официальный сайт отеля; даты и гости там вводятся повторно. В этом архиве нет серверной части, базы данных, API-ключей или платёжного модуля. Цены, дата открытия и условия взяты из экспортированной версии и требуют актуализации владельцем перед рабочим запуском.

## Состав медиа

Все используемые текущей версией фотографии, видео, SVG и TTF включены в `public/assets/` и в готовую папку `dist/assets/`. Это намеренное дублирование: исходники и готовая версия автономны. Не добавлялись фотографии или логотипы Posthotel — от референса использована подача интерфейса.
