## JavaScript — `src/scripts/`

| Файл | Назначение и зависимости |
|---|---|
| `01-video.js` | Видео и пауза; создаёт переменную `video` для сюжетов |
| `02-navigation.js` | Меню, блокировка прокрутки и оформление шапки |
| `03-reservation-modal.js` | Открытие и закрытие окна бронирования; использует меню |
| `04-clock-legacy.js` | Совместимость с прежними часами: ничего не делает без элементов часов |
| `05-room-gallery.js` | Переключение фотографий каталога |
| `06-room-details.js` | Данные четырёх номеров и общие функции диалога `show` / `close` |
| `07-booking.js` | Проверка дат, число ночей и итоговый диалог; использует `show` |
| `08-spa-tabs.js` | Переключение фото и текста спа, управление с клавиатуры |
| `09-hero-stories.js` | Четыре сюжета первого экрана; использует `video` |
| `10-booking-bar.js` | Нижняя панель и синхронизация дат с окном; использует `nextDay`, `arrival`, `departure`, `reservation` |

Данные номера дублируются в карточке и объекте `roomData` в `06-room-details.js`: при изменении названия, цены или фотографии обновите оба места. Тексты сюжетов хранятся в `09-hero-stories.js`; стартовый сюжет также присутствует в `hero.html`.

## CSS — `src/styles/`

- `01-foundation.css` → `dist/style.css`: шрифты, базовые элементы, диалоги и общая адаптивность.
- `02-catalogue-layout.css` → `dist/ritz.css`: структура каталога и окна бронирования; также сохранены неиспользуемые стили прежней главной для точного экспорта.
- `04-motion.css` → `dist/motion.css`: все анимации и плавные переходы — переход между страницами, индикатор прокрутки, первый экран, появление блоков, окна и меню, FAQ, наведение. Подключается последним; при `prefers-reduced-motion: reduce` движение отключено.
- `03-posthotel-theme.css` → `dist/posthotel.css`: актуальное оформление Posthotel, компоненты главной, нижняя панель и финальные мобильные переопределения.

Порядок каскада намеренно сохранён. Это позволяет собрать экспорт без изменения текущего внешнего вида. Для полной изоляции блока в другом CSS-окружении потребуется перенести его зависимые селекторы или ограничить их собственным контейнером.
